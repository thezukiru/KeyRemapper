## 🚀 Что это

**KeyRemapper** — программа для Windows на C#, которая перехватывает нажатия клавиш и выполняет скрипты автоматического ввода текста.

Идеально подходит для **ролевых серверов GTA SA** (GTA San Andreas Multiplayer), где нужно быстро вводить длинные команды `/me`, `/do`, `/say` и другие RP-действия.

**Как это работает:**
1. Вы привязываете клавишу к файлу скрипта в `config.txt`
2. Нажимаете эту клавишу в игре
3. Программа автоматически вводит текст из скрипта с нужными задержками

## ⚡ Быстрый старт

### 1. Компиляция

```bash
compile.bat
```

Создаст файл `KeyRemapper.exe` в текущей директории.

### 2. Настройка биндингов

Отредактируйте файл `config.txt`:

```
# Формат: Клавиша=файл_скрипта.txt
Ctrl+1=medcard.txt
Ctrl+2=inspection.txt
NumPad5=quick_action.txt
```

### 3. Создание скрипта

Создайте файл скрипта (например, `medcard.txt`):

```
{T}[0.1]/me достаёт медкарту{Enter}
[0.3]{T}[0.1]/say Здравствуйте! Вот ваша медкарта.{Enter}
```

### 4. Запуск

```bash
KeyRemapper.exe
```

Программа запустится и будет работать в фоновом режиме. Откройте GTA SA, нажмите привязанную клавишу — скрипт выполнится автоматически!

## 📝 Синтаксис скриптов

### Задержки

```
[0.5]    — задержка 0.5 секунды
[1]      — задержка 1 секунда
[2.5]    — задержка 2.5 секунды
```

### Специальные клавиши

| Клавиша | Запись в скрипте |
|:---|:---|
| T (открыть чат) | `{T}` |
| Enter | `{Enter}` |
| Tab | `{Tab}` |
| Escape | `{Esc}` |
| F1–F12 | `{F1}` … `{F12}` |
| Пробел | `{Space}` |
| Backspace | `{Backspace}` |
| Delete | `{Delete}` |
| Стрелки | `{Left}`, `{Up}`, `{Right}`, `{Down}` |
| Home / End | `{Home}`, `{End}` |
| PageUp / PageDown | `{PageUp}`, `{PageDown}` |

### Режим вставки через буфер обмена

Добавьте `!` в начале строки для быстрой вставки через `Ctrl+V`:

```
!
{T}[0.1]Очень длинный текст, который вставится мгновенно{Enter}
```

> ⚠️ Буфер обмена **не работает** в некоторых текстовых чатах игр. В этом случае используйте посимвольный режим.

### Обычный текст

Любой текст вводится как есть:

```
/say Привет всем!
/me подошёл к прилавку
/do На столе лежит документ
```

## 🔀 Система ветвления

Система ветвления позволяет создавать **интерактивные скрипты** с выбором действий прямо во время выполнения.

### Метки и переходы

```
{LABEL=имя_метки}          — объявление метки
{GOTO=имя_метки}           — безусловный переход
```

### Условные переходы

**Бинарный выбор (да/нет):**
```
{GOTO=ветка_да;YES=RSHIFT;NO=RCTRL}
```

**Подтверждение:**
```
{GOTO=ветка_да;CONFIRM=RSHIFT;CANCEL=ESC}
```

**Циклы:**
```
{GOTO=начало_цикла;REPEAT=RCTRL;YES=RSHIFT}
```

**Множественный выбор (F1–F12):**
```
{GOTO=ветка_по_умолчанию;F1=ветка1;F2=ветка2;F3=ветка3}
```

### Ветвление

```
{WAIT_BRANCH=RSHIFT:да;RCTRL:нет}

{BRANCH=да}
  say Вариант выбран!{Enter}
{END_BRANCH}

{BRANCH=нет}
  say Отмена{Enter}
{END_BRANCH}
```

### Доступные клавиши для условий

| Клавиша | Код |
|:---|:---|
| Right Shift | `RSHIFT` |
| Left Shift | `LSHIFT` |
| Right Ctrl | `RCTRL` |
| Left Ctrl | `LCTRL` |
| Right Alt | `RALT` |
| Left Alt | `LALT` |
| F1–F12 | `F1` … `F12` |
| Escape | `ESC` |

> ✅ Поддерживаются **русские имена** меток и веток.
> ✅ Защита от бесконечных циклов (лимит 100 итераций).

## 🖱 Управление мышью

```
{GET_MOUSE}                  — вывести координаты мыши в консоль
{MOVE_MOUSE=X;Y}             — переместить курсор
{CLICK_MOUSE}                — левый клик в текущей позиции

{RIGHT_CLICK}                — правый клик
{RIGHT_CLICK=X;Y}            — переместить, правый клик, вернуть
{MIDDLE_CLICK}               — средний клик
{MIDDLE_CLICK=X;Y}           — переместить, средний клик, вернуть

## 📊 Overlay визуализация

При выполнении скрипта появляется **полупрозрачное окно** поверх игры, показывающее:

- 📝 **7 строк** контекста: 3 прошлые + текущая + 3 следующие
- 🎨 **Цветовое выделение** для разных типов команд
- 📍 **Breadcrumbs** — путь выполнения (например: `в_сознании > проверка_пульса`)
- ×N **Счётчик итераций** для циклов

### Иконки команд

| Иконка | Команда |
|:---|:---|
| 🔀 | `WAIT_BRANCH` — выбор ветки |
| ➜ | `GOTO` — переход к метке |
| 🏷 | `LABEL` — метка |
| ┌ | `BRANCH` — начало ветки |
| └ | `END_BRANCH` — конец ветки |
| ⏸ | Ожидание ввода |
| ▶ | Текущая строка |
| • | Будущие строки |

### Цветовая схема

| Тип | Текущая строка | Будущие строки |
|:---|:---|:---|
| WAIT_BRANCH | 🟠 Оранжевый | Приглушённый |
| GOTO | 🟢 Зелёный | Приглушённый |
| LABEL | 🟣 Фиолетовый | Приглушённый |
| BRANCH | 🔵 Голубой | Приглушённый |
| Обычный текст | 🔷 Яркий cyan | Светло-серый |
| Прошлые строки | ⬛ Тёмно-серый | — |

> 🖱 Окно overlay можно **перетаскивать** мышкой в любое место экрана.

## ⚙️ Конфигурация

Файл `config.txt` в корне проекта:

```
# Комментарии начинаются с #
# Формат: Модификаторы+Клавиша=файл_скрипта.txt

# Простые биндинги
Ctrl+1=medcard.txt

Ctrl+NumPad0=reset.txt

# Комбинации модификаторов
Ctrl+Shift+R=special_script.txt

### Поддерживаемые модификаторы

- `Ctrl`, `Shift`, `Alt`
- Цифры `0`–`9` (автоматически преобразуются в `D0`–`D9`)
- Клавиши нумпада (см. [Клавиши нумпада](#-клавиши-нумпада))

## 📂 Примеры скриптов

### Пример 1: Простой скрипт

```
{T}[0.1]/say Проверим ваше давление.{Enter}
[0.05]{T}[0.1]/me достаёт тонометр{Enter}
[1]{T}[0.1]/do Тонометр показывает 120/80{Enter}
```

### Пример 2: Быстрый ввод через буфер обмена

```
!
{T}[0.1]Этот текст будет вставлен мгновенно через Ctrl+V{Enter}
```

### Пример 3: Медицинский осмотр с ветвлением

Полный пример с условными переходами, циклами и множественным выбором:

```
!
{F8}[0.1]say Начинаю медицинский осмотр пострадавшего.{Enter}
[0.5]me подошел к пострадавшему{Enter}

{LABEL=проверка_сознания}
[0.5]do Пострадавший в сознании?{Enter}
[0.1]b /do Да (RShift) или /do Нет (RCtrl){Enter}
{WAIT_BRANCH=RSHIFT:в_сознании;RCTRL:без_сознания}

{BRANCH=в_сознании}
say Пострадавший в сознании{Enter}
me задает вопросы пострадавшему{Enter}
{GOTO=проверка_пульса}
{END_BRANCH}

{BRANCH=без_сознания}
say Пострадавший без сознания{Enter}
me проверяет дыхание{Enter}
[0.5]do Дыхание есть?{Enter}
[0.1]b /do Да (RShift) или /do Нет (RCtrl){Enter}
{GOTO=реанимация;NO=RCTRL;YES=RSHIFT}
{END_BRANCH}

{LABEL=реанимация}
say Дыхания нет! Начинаю реанимацию!{Enter}
{LABEL=цикл_срр}
me начал непрямой массаж сердца{Enter}
[2]me продолжает массаж сердца{Enter}
[2]me делает искусственное дыхание{Enter}
[0.5]do Появился пульс?{Enter}
[0.1]b /do Да (RShift) или /do Повторить (RCtrl){Enter}
{GOTO=цикл_срр;REPEAT=RCTRL;YES=RSHIFT}
say Пульс восстановлен!{Enter}

{LABEL=проверка_пульса}
[0.5]me приложил два пальца к сонной артерии{Enter}
[0.5]do Пульс есть?{Enter}
[0.1]b /do Да (RShift) или /do Нет (RCtrl){Enter}
{GOTO=госпитализация;YES=RSHIFT;NO=RCTRL}
say Пульс слабый, требуется помощь{Enter}
[0.5]do Начать реанимацию?{Enter}
[0.1]b /do Да (RShift) или /do Отмена (Esc){Enter}
{GOTO=реанимация;CONFIRM=RSHIFT;CANCEL=ESC}

{LABEL=госпитализация}
say Готовлю пострадавшего к транспортировке{Enter}
me вызвал скорую помощь{Enter}
[0.5]do Срочность госпитализации?{Enter}
[0.1]b /do Высокая (F1) / Средняя (F2) / Низкая (F3){Enter}
{GOTO=конец;F1=срочная;F2=плановая;F3=низкая}

{LABEL=срочная}
say Код красный! Срочная госпитализация!{Enter}
{GOTO=конец}

{LABEL=плановая}
say Плановая госпитализация{Enter}
{GOTO=конец}

{LABEL=низкая}
say Амбулаторное лечение{Enter}

{LABEL=конец}
say Процедура завершена{Enter}
```

## 🔧 Компиляция

### Требования

- **Windows** (7/8/10/11)
- **.NET Framework 4.0** или выше (обычно уже установлен)
- Никаких дополнительных зависимостей не требуется!

### Сборка

```bash
compile.bat
```

Используется встроенный компилятор .NET Framework:
```
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe
```

### Запуск

```bash
KeyRemapper.exe
```

### Остановка

```bash
taskkill /F /IM KeyRemapper.exe
```

Или нажмите `Win` 3 раза за секунду.

## ⚠️ Известные ограничения

1. **Буфер обмена** не работает в некоторых текстовых чатах игр — используйте посимвольный режим
2. **Английские символы** вводятся медленнее русских (через SendKeys)
3. **Переключение раскладки** добавляет задержку ~100мс
4. Программа работает **только на Windows** (использует Win32 API хуки)
5. Требуется **.NET Framework 4.0+**
