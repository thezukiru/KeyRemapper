# KeyRemapper v0.0.1 - Система ветвления и меток

## Что нового в v0.0.1

### Система ветвления и условных переходов
Добавлена полноценная система меток, переходов и ветвления для создания сложных интерактивных скриптов с выбором действий.

### Основные возможности:

**1. Метки и безусловные переходы:**
```
{LABEL=имя_метки}
{GOTO=имя_метки}
```

**2. Условные переходы с выбором:**
```
{GOTO=метка;YES=RSHIFT;NO=RCTRL}
{GOTO=метка;CONFIRM=RSHIFT;CANCEL=ESC}
{GOTO=метка;CONTINUE=RSHIFT;SKIP=RCTRL}
```

**3. Циклы:**
```
{LABEL=начало_цикла}
// ... код цикла ...
{GOTO=начало_цикла;REPEAT=RCTRL;YES=RSHIFT}
```

**4. Ветвление:**
```
{WAIT_BRANCH=RSHIFT:ветка1;RCTRL:ветка2}

{BRANCH=ветка1}
// ... код ветки 1 ...
{END_BRANCH}

{BRANCH=ветка2}
// ... код ветки 2 ...
{END_BRANCH}
```

**5. Множественный выбор:**
```
{GOTO=метка;F1=вариант1;F2=вариант2;F3=вариант3}
```

### Особенности:

- ✅ Поддержка русских имен меток и веток
- ✅ Защита от бесконечных циклов (лимит 100 итераций)
- ✅ Breadcrumbs визуализация в overlay (показывает путь выполнения)
- ✅ Счетчик итераций для циклов
- ✅ Поддержка клавиш: RSHIFT, LSHIFT, RCTRL, LCTRL, RALT, LALT, F1-F12, ESC

## Быстрый старт

1. Запустите `KeyRemapper.exe`
2. Настройте биндинги в `config.txt`:
   ```
   Ctrl+1=instructions.txt
   Ctrl+2=branch_test.txt
   ```
3. Создайте скрипт с ветвлением (см. `branch_test.txt`)
4. Нажмите биндинг в GTA SA
5. Следуйте подсказкам на экране и выбирайте варианты клавишами

## Overlay визуализация

### Улучшенный дизайн (обновлено 26.04.2026):

**Новые возможности:**
- 🔀 Полное отображение WAIT_BRANCH без сокращений с автоматическим переносом строк
- 🎨 Цветовое выделение для разных типов команд
- 🎯 Специальные иконки для каждого типа команды
- 📏 Компактное расположение строк - теперь отображается 7 строк (3 прошлые + текущая + 3 следующие)
- 📐 Увеличенный размер окна (500x260px) для лучшей читаемости

**Иконки команд:**
- 🔀 WAIT_BRANCH - выбор ветки
- ➜ GOTO - переход к метке
- 🏷 LABEL - метка
- ┌ BRANCH - начало ветки
- └ END_BRANCH - конец ветки
- ⏸ WAIT - пауза выполнения
- ▶ Обычный текст (текущая строка)
- • Обычный текст (будущие строки)
- ✓ Выполненные команды

**Цветовая схема:**
- WAIT_BRANCH: оранжевый (текущая), приглушенный оранжевый (будущая)
- GOTO: зеленый (текущая), приглушенный зеленый (будущая)
- LABEL: фиолетовый (текущая), приглушенный фиолетовый (будущая)
- BRANCH/END_BRANCH: голубой (текущая), приглушенный голубой (будущая)
- WAIT: красноватый (текущая), приглушенный красный (будущая)
- Обычный текст: яркий cyan (текущая), светло-серый (будущая)
- Прошлые строки: темно-серый

**Дополнительно:**
- 📍 Breadcrumbs - путь выполнения (например: `в_сознании > проверка_пульса`)
- ×N - счетчик итераций для циклов

## Управление

- **RShift / RCtrl / F1-F12** - выбор варианта в ветвлении
- **Esc** - отмена скрипта в любой момент
- **Win** - остановка выполняющегося скрипта
- **3x Win за секунду** - экстренное закрытие программы

## Технические детали
