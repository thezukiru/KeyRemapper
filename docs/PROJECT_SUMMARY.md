# KeyRemapper - Краткое описание проекта

## Что это
Программа для Windows на C#, которая перехватывает комбинации клавиш и выполняет скрипты автоматического ввода текста.

## Основные файлы
- `KeyRemapper.cs` - основной код программы
- `compile.bat` - компиляция в KeyRemapper.exe
- `config.txt` - конфигурация биндингов клавиш
- `instructions.txt`, `text_input.txt` - файлы со скриптами ввода

## Возможности

### 1. Overlay окно (визуальный индикатор выполнения)

**Отображение текущей строки:**
- Полупрозрачное окно поверх всех приложений
- Показывает текущую строку (с маркером ►) и 2 следующие строки
- Автоматически появляется при запуске скрипта
- Автоматически скрывается при завершении или отмене
- Можно перетаскивать мышкой в любое место экрана
- Черный фон с зеленым текстом (стиль терминала)
- Длинные строки обрезаются до 70 символов

### 2. Протокол отмены (безопасность)

**Остановка выполнения скрипта:**
- Нажмите `Win` или `Esc` во время выполнения скрипта для немедленной остановки
- Скрипт прекратит работу и освободит управление

**Экстренное закрытие программы:**
- Нажмите клавишу `Win` 3 раза за 1 секунду для принудительного закрытия программы
- Используется в критических ситуациях, когда нужно мгновенно остановить все

### 3. Множественные биндинги (config.txt)
```
Ctrl+1=instructions.txt
Ctrl+Shift+R=script2.txt
Alt+Q=quick_action.txt
NumPad5=action.txt
```
- Поддержка модификаторов: Ctrl, Shift, Alt
- Поддержка цифр 0-9 (автоматически преобразуются в D0-D9)
- Поддержка клавиш нумпада: NumPad0-NumPad9, Add, Subtract, Multiply, Divide, Decimal
- Комментарии начинаются с #

### 4. Два режима вставки текста

#### Режим буфера обмена (быстрый, мгновенный)
Добавить `!` первой строкой в файле:
```
!
{T}[0.1]/say Привет
{Enter}
```
- Вставка через Ctrl+V
- Мгновенная скорость
- НЕ работает в некоторых текстовых чатах игр

#### Посимвольный режим (работает везде)
Без флага `!`:
```
{T}[0.1]/say Привет
{Enter}
```
- Быстрый ввод через keybd_event для русских символов
- Fallback на SendKeys для английских символов
- Автоматическое переключение на русскую раскладку перед вводом

### 5. Синтаксис скриптов

**Задержки:**
- `[0.5]` - задержка 0.5 секунды
- `[1]` - задержка 1 секунда

**Специальные клавиши:**
- `{T}` - клавиша T (работает через виртуальный код, независимо от раскладки)
- `{Enter}` - Enter
- `{Tab}` - Tab
- `{Esc}` - Escape
- `{F1}` - `{F12}` - функциональные клавиши
- `{Space}`, `{Backspace}`, `{Delete}`, `{Home}`, `{End}`, `{PageUp}`, `{PageDown}`
- `{Left}`, `{Up}`, `{Right}`, `{Down}` - стрелки

**Управление мышью:**
- `{GET_MOUSE}` - Получить текущие координаты мыши (вывод в консоль)
- `{MOVE_MOUSE=X;Y}` - Переместить курсор на координаты X;Y
- `{CLICK_MOUSE}` - Клик левой кнопкой в текущей позиции
- `{CLICK_MOUSE=X;Y}` - Переместить, кликнуть и вернуть курсор обратно
- `{RIGHT_CLICK}` - Клик правой кнопкой в текущей позиции
- `{RIGHT_CLICK=X;Y}` - Переместить, кликнуть правой и вернуть курсор
- `{MIDDLE_CLICK}` - Клик средней кнопкой в текущей позиции
- `{MIDDLE_CLICK=X;Y}` - Переместить, кликнуть средней и вернуть курсор

**Система ветвления и меток (v0.3):**

*Метки и переходы:*
- `{LABEL=имя_метки}` - Объявление метки (поддерживает русские символы)
- `{GOTO=метка}` - Безусловный переход к метке
- `{GOTO=метка;YES=RSHIFT;NO=RCTRL}` - Переход с выбором (YES - к метке, NO - следующая строка)
- `{GOTO=метка;CONFIRM=RSHIFT;CANCEL=ESC}` - Переход с подтверждением
- `{GOTO=метка;CONTINUE=RSHIFT;SKIP=RCTRL}` - CONTINUE - к метке, SKIP - пропустить блок
- `{GOTO=метка;REPEAT=RCTRL;YES=RSHIFT}` - REPEAT - повторить (цикл), YES - выйти
- `{GOTO=метка;F1=метка1;F2=метка2;F3=метка3}` - Множественный выбор

*Ветвление:*
- `{WAIT_BRANCH=KEY1:ветка1;KEY2:ветка2}` - Ожидание выбора ветки
- `{BRANCH=имя_ветки}` - Начало ветки
- `{END_BRANCH}` - Конец ветки

*Особенности:*
- Поддержка русских имен меток и веток
- Защита от бесконечных циклов (лимит 100 итераций)
- Breadcrumbs визуализация в overlay (показывает путь выполнения)
- Счетчик итераций для циклов
- Поддерживаемые клавиши: RSHIFT, LSHIFT, RCTRL, LCTRL, RALT, LALT, F1-F12, ESC

**Обычный текст:**
```
Просто текст вводится как есть
/say Команда с символами
```

**Пример скрипта:**
```
{T}[0.1]/say Проверим Ваше давление.
{Enter}
[0.05]{T}[0.1]/do Достаю тонометр.
{Enter}
```

## Технические детали

### Ключевые функции в коде

1. **ConfigParser.LoadConfig()** - загружает биндинги из config.txt
2. **InstructionExecutor.ExecuteInstructions()** - выполняет скрипт из файла
   - Проверяет флаг `!` для режима буфера обмена
   - Вызывает ProcessLine() или ProcessLineForClipboardWithDelay()
   - Проверяет флаг cancelRequested для отмены выполнения
   - Обновляет overlay окно на каждой строке
3. **InstructionExecutor.RequestCancel()** - запрашивает отмену выполнения скрипта
4. **InstructionExecutor.IsExecuting()** - проверяет, выполняется ли скрипт
5. **InstructionExecutor.UpdateOverlay()** - обновляет текст в overlay окне
6. **TypeTextFast()** - быстрый ввод через keybd_event
   - Автоматически переключает на русскую раскладку
   - Использует VkKeyScan для преобразования символов в виртуальные коды
   - Fallback на SendKeys для символов недоступных в текущей раскладке
7. **PasteViaClipboard()** - вставка через буфер обмена в STA потоке
8. **KeyRemapper.HookCallback()** - перехват клавиш через Windows Hook
   - Обрабатывает протокол отмены (Win/Esc)
   - Отслеживает множественные нажатия Win для экстренного закрытия
9. **OverlayForm** - полупрозрачное окно для отображения прогресса
   - Показывает текущую и следующие строки
   - Поддержка перетаскивания мышкой

### Важные особенности

1. **Overlay окно:**
   - Полупрозрачное (70% прозрачности) черное окно с зеленым текстом
   - Всегда поверх других окон (TopMost)
   - Показывает текущую строку с маркером ► и 2 следующие
   - Можно перетаскивать мышкой
   - Автоматически скрывается при завершении/отмене скрипта
   - Размер: 600x150 пикселей

2. **Протокол отмены:**
   - Win/Esc останавливают выполнение скрипта
   - 3 нажатия Win за секунду принудительно закрывают программу
   - Флаги cancelRequested и isExecuting для безопасной остановки

3. **Раскладка клавиатуры:**
   - Программа принудительно переключает на русскую раскладку перед вводом
   - Русские символы вводятся быстро через keybd_event
   - Английские символы вводятся через SendKeys (медленнее, но работает)

4. **Экранирование специальных символов SendKeys:**
   - `+^%~(){}[]` автоматически экранируются в `{+}{^}{%}` и т.д.

5. **Минимальные задержки:**
   - 50мс между операциями в режиме буфера обмена
   - 1мс между символами в посимвольном режиме
   - 100мс на переключение раскладки

6. **Клавиша T:**
   - Добавлена в keyMap с виртуальным кодом 0x54
   - Работает независимо от раскладки

## Известные ограничения

1. Буфер обмена не работает в некоторых текстовых чатах игр
2. Английские символы вводятся медленнее русских (через SendKeys)
3. Переключение раскладки добавляет задержку ~100мс
4. SendKeys имеет ограничения по скорости

## Компиляция и запуск

```bash
compile.bat          # Компиляция
KeyRemapper.exe      # Запуск
taskkill /F /IM KeyRemapper.exe  # Остановка
```

## Примеры использования

### config.txt
```
# Основные биндинги
Ctrl+1=text_input.txt
Ctrl+2=instructions.txt

# Нумпад
NumPad1=quick1.txt
NumPad2=quick2.txt
```

### instructions.txt (посимвольный режим)
```
{T}[0.1]/say Проверим Ваше давление.
{Enter}
```

### text_input.txt (режим буфера обмена)
```
!
{T}[0.1]Большой текст для быстрой вставки
{Enter}
```

### branch_test.txt (система ветвления)
```
!
{F8}say Начинаю медицинский осмотр{Enter}

{LABEL=проверка_сознания}
do Пострадавший в сознании?{Enter}
b /do Да (RShift) или /do Нет (RCtrl){Enter}
{WAIT_BRANCH=RSHIFT:в_сознании;RCTRL:без_сознания}

{BRANCH=в_сознании}
say Пострадавший в сознании{Enter}
{GOTO=проверка_пульса}
{END_BRANCH}

{BRANCH=без_сознания}
say Пострадавший без сознания{Enter}
do Дыхание есть?{Enter}
{GOTO=реанимация;NO=RCTRL;YES=RSHIFT}
{END_BRANCH}

{LABEL=реанимация}
say Начинаю реанимацию!{Enter}
{LABEL=цикл_срр}
me делает массаж сердца{Enter}
[2]me продолжает массаж{Enter}
do Появился пульс?{Enter}
{GOTO=цикл_срр;REPEAT=RCTRL;YES=RSHIFT}

{LABEL=проверка_пульса}
me проверяет пульс{Enter}
do Пульс есть?{Enter}
{GOTO=госпитализация;YES=RSHIFT;NO=RCTRL}

{LABEL=госпитализация}
say Вызываю скорую{Enter}
do Срочность? (F1/F2/F3){Enter}
{GOTO=конец;F1=срочная;F2=плановая;F3=низкая}

{LABEL=срочная}
say Код красный!{Enter}
{GOTO=конец}

{LABEL=плановая}
say Плановая госпитализация{Enter}
{GOTO=конец}

{LABEL=низкая}
say Амбулаторное лечение{Enter}

{LABEL=конец}
say Процедура завершена{Enter}
```
