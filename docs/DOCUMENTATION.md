## 🚀 Быстрый старт

### Что это такое

KeyRemapper - это программа для Windows на C#, которая перехватывает комбинации клавиш и выполняет скрипты автоматического ввода текста. Идеально подходит для ролевых игр (GTA SA RP) и автоматизации повторяющихся действий.

**Основные преимущества:**
- ✅ Множественные биндинги клавиш
- ✅ Два режима ввода (быстрый через буфер обмена и посимвольный)
- ✅ Система ветвления и условных переходов
- ✅ Текстовые макросы (Text Expander) с триггерами в чате
- ✅ Управление мышью
- ✅ Визуальный overlay с отображением прогресса
- ✅ Протокол безопасной отмены
- ✅ Проверка активности GTA SA

### Установка и запуск

1. **Скомпилируйте программу:**
   ```bash
   compile.bat
   ```

2. **Запустите:**
   ```bash
   KeyRemapper.exe
   ```

3. **Настройте биндинги** в `config.txt`:
   ```
   Ctrl+1=instructions.txt
   Ctrl+2=medcard.txt
   NumPad5=quick_action.txt
   ```

4. **Создайте скрипт** (например, `instructions.txt`):
   ```
   {T}[0.1]/say Привет!
   {Enter}
   ```

5. **Нажмите биндинг** в GTA SA и наблюдайте выполнение!

### Первый скрипт

**Простой скрипт (instructions.txt):**
```
{T}[0.1]/say Здравствуйте!
{Enter}
[0.5]{T}[0.1]/me протягивает руку для рукопожатия
{Enter}
```

**Быстрый скрипт через буфер обмена (text_input.txt):**
```
!
{T}[0.1]Большой текст для быстрой вставки
{Enter}
```

### Возможности программы

#### 1. Overlay окно (визуальный индикатор выполнения)

**Отображение текущей строки:**
- Полупрозрачное окно поверх всех приложений
- Показывает 7 строк: 3 прошлые + текущая + 3 следующие
- Автоматически появляется при запуске скрипта
- Автоматически скрывается при завершении или отмене
- Можно перетаскивать мышкой в любое место экрана
- Modern Glass стиль с градиентами и подсветкой
- Цветовое выделение для разных типов команд
- Breadcrumbs визуализация пути выполнения

#### 2. Протокол отмены (безопасность)

**Остановка выполнения скрипта:**
- Нажмите `Win` или `Esc` (3 раза за секунду) во время выполнения для остановки
- Скрипт прекратит работу и освободит управление

**Экстренное закрытие программы:**
- Нажмите клавишу `Win` 3 раза за 1 секунду для принудительного закрытия
- Используется в критических ситуациях

#### 3. Множественные биндинги (config.txt)

```
# Основные биндинги
Ctrl+1=instructions.txt
Ctrl+Shift+R=script2.txt
Alt+Q=quick_action.txt

# Нумпад
NumPad5=action.txt
Ctrl+NumPad0=reset.txt

# Комментарии начинаются с #
```

**Поддерживаемые модификаторы:**
- Ctrl, Shift, Alt
- Цифры 0-9 (автоматически преобразуются в D0-D9)
- Клавиши нумпада (см. [Клавиши NumPad](#клавиши-numpad))

#### 4. Два режима вставки текста

**Режим буфера обмена (быстрый, мгновенный):**
```
!
{T}[0.1]/say Привет
{Enter}
```
- Вставка через Ctrl+V
- Мгновенная скорость
- НЕ работает в некоторых текстовых чатах игр

**Посимвольный режим (работает везде):**
```
{T}[0.1]/say Привет
{Enter}
```
- Быстрый ввод через keybd_event для русских символов
- Fallback на SendKeys для английских символов
- Автоматическое переключение на русскую раскладку

### Синтаксис скриптов

#### Задержки
- `[0.5]` - задержка 0.5 секунды
- `[1]` - задержка 1 секунда
- `[2.5]` - задержка 2.5 секунды

#### Специальные клавиши
- `{T}` - клавиша T (работает через виртуальный код, независимо от раскладки)
- `{Enter}` - Enter
- `{Tab}` - Tab
- `{Esc}` - Escape
- `{F1}` - `{F12}` - функциональные клавиши
- `{Space}`, `{Backspace}`, `{Delete}`
- `{Home}`, `{End}`, `{PageUp}`, `{PageDown}`
- `{Left}`, `{Up}`, `{Right}`, `{Down}` - стрелки

#### Обычный текст
```
Просто текст вводится как есть
/say Команда с символами
```

### Система ветвления и меток

#### Метки и переходы

**Объявление метки:**
```
{LABEL=имя_метки}
```

**Безусловный переход:**
```
{GOTO=имя_метки}
```

**Условные переходы:**

*YES / NO - бинарный выбор:*
```
do Пульс есть?{Enter}
{GOTO=has_pulse;YES=RSHIFT;NO=RCTRL}
```

*CONFIRM / CANCEL - подтверждение:*
```
say Вы уверены?{Enter}
{GOTO=next_step;CONFIRM=RSHIFT;CANCEL=ESC}
```

*CONTINUE / SKIP - пропуск блока:*
```
{GOTO=optional;CONTINUE=RSHIFT;SKIP=RCTRL}
```

*REPEAT - циклы:*
```
{LABEL=loop_start}
me проверяет пульс{Enter}
do Пульс стабилен?{Enter}
{GOTO=loop_start;REPEAT=RCTRL;YES=RSHIFT}
```

*Множественный выбор:*
```
do Степень травмы?{Enter}
{GOTO=default;F1=light;F2=medium;F3=severe}
```

#### Ветвление

**Синтаксис:**
```
{WAIT_BRANCH=KEY1:ветка1;KEY2:ветка2}

{BRANCH=ветка1}
  ... команды для варианта 1 ...
{END_BRANCH}

{BRANCH=ветка2}
  ... команды для варианта 2 ...
{END_BRANCH}
```

**Особенности:**
- ✅ Поддержка русских имен меток и веток
- ✅ Защита от бесконечных циклов (лимит 100 итераций)
- ✅ Breadcrumbs визуализация в overlay
- ✅ Счетчик итераций для циклов
- ✅ Поддерживаемые клавиши: RSHIFT, LSHIFT, RCTRL, LCTRL, RALT, LALT, F1-F12, ESC

### Управление мышью

**Получение координат:**
```
{GET_MOUSE}
```
Выводит текущие координаты мыши в консоль.

**Перемещение курсора:**
```
{MOVE_MOUSE=X;Y}
```
Перемещает курсор на координаты X;Y.

**Клики:**
```
{CLICK_MOUSE}              # Клик в текущей позиции
{CLICK_MOUSE=X;Y}          # Переместить, кликнуть, вернуть курсор
{RIGHT_CLICK}              # Правая кнопка в текущей позиции
{RIGHT_CLICK=X;Y}          # Переместить, кликнуть правой, вернуть
{MIDDLE_CLICK}             # Средняя кнопка в текущей позиции
{MIDDLE_CLICK=X;Y}         # Переместить, кликнуть средней, вернуть
```

**Иконки команд:**

- 🏷 LABEL - метка
- ┌ BRANCH - начало ветки
- └ END_BRANCH - конец ветки
- ⏸ WAIT - пауза выполнения

- • Обычный текст (будущие строки)

**Цветовая схема:**
- WAIT_BRANCH: оранжевый (текущая), приглушенный (будущая)

- BRANCH/END_BRANCH: голубой (текущая), приглушенный (будущая)
- WAIT: красноватый (текущая), приглушенный (будущая)
- Обычный текст: яркий cyan (текущая), светло-серый (будущая)
- Прошлые строки: темно-серый

**Дополнительно:**

### Архитектура проекта

```

├── Models/

│   ├── ConfigParser.cs         # Парсинг config.txt (биндинги + триггеры)
│   ├── InputSimulator.cs       # Эмуляция ввода (Win32 API) + SendBackspaces()
│   ├── InputTracker.cs         # Буфер символов для Text Expander
│   ├── TextExpander.cs         # Движок Text Expander
│   ├── GtaMonitor.cs          # Мониторинг GTA SA с кэшированием
│   ├── BranchingEngine.cs     # Обработка меток, веток, GOTO
│   ├── ScriptEngine.cs        # Главный движок выполнения
│   └── InstructionExecutor.cs # Адаптер для обратной совместимости
├── UI/
│   ├── MainWindow.cs           # Главное окно приложения (список макросов)
│   └── StyledControls.cs       # Кастомные UI компоненты

├── config.txt                  # Конфигурация биндингов и триггеров
└── *.txt                       # Файлы скриптов и текстовых макросов
```

### Ключевые компоненты

#### Models/KeyBinding.cs
Модель данных для хранения биндингов клавиш.
- `Keys Key` - основная клавиша
- `bool Ctrl, Shift, Alt` - модификаторы
- `string InstructionFile` - файл скрипта
- `bool Matches()` - проверка соответствия нажатия

#### Models/TextMacro.cs
Модель данных для текстовых макросов (Text Expander).
- `string Trigger` - триггер (например, ".текст")
- `string FilePath` - путь к файлу с текстом
- `string Content` - содержимое файла
- `bool UseClipboard` - режим вставки через буфер обмена
- `bool Matches(string buffer)` - проверка, заканчивается ли буфер на триггер

#### Core/ConfigParser.cs
Статический класс для парсинга config.txt.
- `LoadConfig()` - загружает биндинги клавиш
- `LoadTextMacros()` - загружает текстовые макросы (формат: "триггер"=файл.txt)
- `ParseKeyCombo()` - парсит строки типа "Ctrl+Shift+E"

#### Core/InputSimulator.cs
Win32 API импорты для эмуляции ввода.
- `TypeTextFast()` - быстрый ввод через keybd_event
- `PasteViaClipboard()` - вставка через буфер обмена
- `SwitchToRussian()` - переключение раскладки
- `SendBackspaces(int count)` - отправка последовательных Backspace для удаления триггера
- Методы для работы с мышью

#### Core/InputTracker.cs
Отслеживание ввода символов для Text Expander.
- Буфер последних 50 символов (StringBuilder)
- `AddCharacter(char c)` - добавление символа в буфер
- `GetBuffer()` - получение текущего буфера
- `Clear()` / `Reset()` - очистка буфера (при потере фокуса GTA)

#### Core/TextExpander.cs
Движок Text Expander (замена триггеров на текст).
- Загрузка списка макросов из ConfigParser
- `ProcessKeyPress(Keys key, char character)` - обработка нажатия клавиши
- `CheckAndExpand(Keys triggerKey)` - проверка буфера на совпадение с триггерами
- `ExecuteMacro(TextMacro macro, Keys triggerKey)` - удаление триггера, вставка текста, отправка Enter
- Защита от рекурсии через флаг `isExpanding`
- Работает только когда GTA SA активна и скрипт не выполняется

#### Core/GtaMonitor.cs
Мониторинг активности GTA SA с кэшированием.
- Кэширование Process объекта GTA SA
- Кэширование результатов проверки на 100мс
- `IsGtaSaActive()` - оптимизированная проверка

#### Core/BranchingEngine.cs
Обработка меток, веток и GOTO.
- `ParseLabelsAndBranches()` - предварительный парсинг
- `ProcessBranchingCommands()` - обработка команд ветвления
- `WaitForKeyPress()` - ожидание выбора пользователя
- Защита от бесконечных циклов

#### Core/ScriptEngine.cs
Главный движок выполнения скриптов (~600 строк).
- `ExecuteInstructions()` - запуск скрипта
- `ProcessLine()` / `ProcessLineForClipboard()` - обработка строк
- Интеграция с BranchingEngine, InputSimulator, GtaMonitor
- Проверка GTA SA каждые 3 строки (безопасность!)

#### Core/InstructionExecutor.cs
Адаптер для обратной совместимости.
- Делегирует вызовы к ScriptEngine
- Сохраняет старый API для KeyRemapper класса

#### KeyRemapper.cs
Главный класс и OverlayForm (~730 строк).
- `HookCallback()` - перехват клавиш через Windows Hook
- Интеграция с TextExpander: проверка триггеров когда GTA активна и скрипт не выполняется
- `GetCharacterFromVkCode()` - получение символа с учётом текущей раскладки (ToAscii)
- Обработка протокола отмены (Win/Esc)
- `OverlayForm` - полупрозрачное окно для отображения прогресса

## 💡 Концепция и идеи

### Концепция системы ветвления

Полная концепция системы ветвления описана в файле `IDEA.md`. Основные моменты:

**Проблема:** При РП игре часто возникают ситуации с выбором (да/нет, несколько вариантов).

**Решение:** WAIT_BRANCH + GOTO с аргументами для создания интерактивных скриптов.

**Логика работы:**
- GOTO без аргументов → немедленный переход
- GOTO с аргументами → ожидание нажатия клавиши
- Действия: YES, NO, CONFIRM, CANCEL, CONTINUE, SKIP, REPEAT

**Визуализация:** Breadcrumbs + адаптивное отображение в overlay.

## 📝 Известные ограничения

1. Буфер обмена не работает в некоторых текстовых чатах игр
2. Английские символы вводятся медленнее русских (через SendKeys)
3. Переключение раскладки добавляет задержку ~100мс
4. SendKeys имеет ограничения по скорости
5. C# 5 ограничения (нет ReadOnlySpan, ValueTuple, pattern matching)
6. Text Expander: буфер символов отслеживает только нажатия клавиш, но не реальное содержимое чата (ошибка возможна при удалении мышкой)
